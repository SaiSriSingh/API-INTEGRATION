DESCRIPTION :
The main goal of this project was to demonstrate how APIs can be integrated into a web application to fetch and display data dynamically.
I wanted to keep the design and functionality simple yet effective so that anyone reviewing the project could clearly understand how API requests and responses work in a full-stack environment.

For the front end, I used HTML and CSS. 
The HTML file (index.html) lays out the structure of the web page, including elements like buttons, containers, and text fields.
I styled the page using style.css to give it a clean and modern appearance. 
While the design is minimal, it serves the purpose of allowing users to interact with the page easily.

On the back end, I used Python, specifically with the Flask framework.
My Python script (app.py) handles routing and logic. 
When a user interacts with the front end—like clicking a button—it triggers a request to my Flask server. 
The server then makes a call to an external API, processes the data it receives, and sends it back to the front end for display.

One of the most useful aspects of this project was learning to work with API endpoints, manage JSON data, and update the front end with that data in real-time. 
I also created a requirements.txt file to list all the dependencies, making it easy for others to set up the project environment using pip install.
